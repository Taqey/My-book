# دليل عينات تصميم الكتاب المدرسي (Meezan AI & Programming Magazine Style)

لقد تم تحليل كتابك الأصلي: `Programming-ArtificialIntelligence-En-EB-part2 (1).pdf` وتم إعداد النموذج الأولي لأسلوب **المجلة التعليمية العصرية (Educational Tech Magazine)**.

---

## 📁 محتويات هذا المجلد (`D:\MY book\Magazine_Design_Kit\`)

1. **`programmer_mascot.jpg`**:
   - تصميم شخصية كرتونية مبرمج شاب (3D Pixar-Style) يحمل تابلت ذكاء اصطناعي ونظارة برمجية، مع بطاقة تصميم تفصيلية وتعبيرات وجه تناسب الشرح والملاحظات.

2. **`magazine_preview.html`**:
   - **صفحة تفاعلية حية (Visual Interactive Mockup)**: يمكنك فتح هذا الملف في أي متصفح (Edge أو Chrome) لمعاينة التصميم والشكل النهائي لصفحتين متقابلتين (Spread):
     - **صفحة الشرح**: ترويسة، كولومات مجلة (2-column)، مساحة الـ Dropcap، جدول مقارنة ملون، وبوكس الملاحظة الكرتوني الخاص بالشخصية مع بالونة الكلام، وصندوق "Pause & Think".
     - **صفحة الأسئلة**: تشمل 3 أنماط من الأسئلة:
       1. اختيار من متعدد (MCQ Grid Cards).
       2. حالة واقعية / قطعة وعليها أسئلة (Case Study Box) مع مساحة إجابة مقالية.
       3. أسئلة صح وخطأ سريعة (True / False Speed Drill).

3. **`Build_InDesign_Template.jsx`**:
   - سكربت لبرنامج **Adobe InDesign**. بمجرد تشغيله داخل InDesign، يقوم بإنشاء:
     - مستند بمقاس A4 صفحات متقابلة (Facing Pages) بنظام الأعمدة المزدوجة والهوامش.
     - مكتبة الألوان الخاصة بالمجلة (CMYK Swatches).
     - أنماط الفقرات الجاهزة (Paragraph Styles) للعناوين والفقرات والأسئلة لضمان التناسق.
     - أنماط الكائنات (Object Styles) لإطارات وصناديق الشخصية الكرتونية.

- **الخطوط الموصى بها**:
